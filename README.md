# OpenBot Apps for Home Assistant (Unofficial)

Community Home Assistant add-on repository for [OpenBot](https://openbot.run).
Not affiliated with Synthetify Labs. See [NOTICE](NOTICE): OpenBot is licensed
for **noncommercial use only** (PolyForm Noncommercial 1.0.0).

## Install

1. Home Assistant > Settings > Add-ons > Add-on Store > ⋮ > Repositories.
2. Add `https://github.com/michalchecinski/openbot-ha-addon`.
3. Install **OpenBot Server (Unofficial)** and read its Documentation tab.

## Add-ons

- [OpenBot Server](openbot-server/DOCS.md): runs the headless OpenBot server.
